# Выздоравливай, Мария ♥

Игра в браузере: раннер (прыгай, лечись, убегай от вирусов, лети к Руслану), казино «Дикий Запад» («Ковбой против Быка» — ставки на раздачу техасского холдема с джекпотом и рейтингом дня, «Морской тир» — стрельба по рыбкам, и суши-слоты) и магазин с нарядами, питомцами, суперсилами и настоящими купонами.

- Фото: положи `assets/maria.jpg` и `assets/ruslan.jpg` (квадратные фото лица смотрятся лучше всего).
- Все тексты, имена и купоны — в `js/config.js`.
- Монеты и покупки хранятся в браузере (localStorage). Монеты игровые, настоящие деньги не участвуют.
- Превью: `?preview=2`, `3`, `end`, `casino`, `ranch`, `fish`, `slots`, `shop`.
- «Ковбой против Быка»: множители, джекпот, фишки и награды — в `js/ranch/payouts.js`. Тесты: `npm test`, симуляция выплат: `npm run sim` (нужен Node 20+).
- «Морской тир»: рыбы, множители, `targetRTP`, заморозка — в `js/fish/config.js`. Проверка экономики: `npm run sim:fish` (1 млн выстрелов), точные шансы слотов: `npm run sim:slots`.
